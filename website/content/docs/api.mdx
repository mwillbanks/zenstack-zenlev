title: 'Programmatic API'
description: 'Run the command service from deployment code.'
---

```ts
import { createZenlev } from '@mwillbanks/zenstack-zenlev'
import { db } from './db'

const zenlev = await createZenlev({ client: db, migrationsDir: 'migrations' })

try {
  const result = await zenlev.migrate.apply({
    namespace: ['predeploy'],
    planOnly: true,
  })
  console.log(result.plan)

  await zenlev.migrate.apply({ namespace: ['predeploy'] })
} finally {
  await zenlev.close()
}
```

`close()` waits for in-flight command work and disposes factory-owned resources once. A supplied client stays under the caller's ownership.

## Command methods

The `db.push()` method compares and changes schemas through the same service.

The `migrate` object exposes `create`, `apply`, `rollback`, `status`, `tree`, `remove`, `resolve`, `reshape`, and `recover`.

CLI comma-separated lists become arrays in API options. Rollback uses `mode: 'cascade' | 'compensate'`.

## Standalone Kysely

```ts
import { createKyselyAdapter, createZenlev } from '@mwillbanks/zenstack-zenlev'
import { kysely } from './database'

const zenlev = await createZenlev({
  adapter: createKyselyAdapter(kysely, 'postgresql'),
})
```

The adapter uses the supplied Kysely instance. Declare the database dialect explicitly. Migration context exposes that query builder through `ctx.db.kysely`.
